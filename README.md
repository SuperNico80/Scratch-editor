# Scratch editor
Scratch editor translates Blocks language to Arduino code. Useful for beginners. 
# How to use
- On start block targets void setup()
- Forever block targets void loop()
- Header block targets the top of the file.
# Notes
- Scratch editor uses Windows 7 build 7600 (Version 6.1)
- You can load your previous projects (*.json, *.xml), but not Arduino projects (*.ino)
